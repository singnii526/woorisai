# 우리사이 — 커플 공유 캘린더

공개 화면(PWA): `index.html` + `sw.js` + `manifest.webmanifest` + `icons/`. 서버는 [../couple-share-server/](../couple-share-server/).

## 두 가지 모드
- **데모 모드** — `index.html` 의 `DEFAULT_API` 가 비어 있을 때. 서버 없이 이 기기 안에서만 동작(일정은 localStorage, 사진은 IndexedDB). 샘플 데이터와 "상대방 활동 시뮬레이션"이 있다.
- **서버 모드** — `DEFAULT_API` 에 서버 주소가 있을 때(배포 스크립트가 채움). 실제 카카오 로그인, 두 기기 간 공유, 휴대폰 푸시.
  개발 중에는 주소 뒤에 `?api=http://localhost:8787` 을 붙이면 그 서버를 쓴다(`?api=` 로 해제).

서버 모드에서 쓴 기록은 먼저 화면에 반영하고 "보낼 목록"(outbox)에 쌓았다가 순서대로 보낸다. 인터넷이 끊겨도 다시 연결되면 이어서 보낸다.

## 기능
- **카카오 로그인**: 서버가 카카오 REST API로 처리(닉네임만 받음). 데모 모드는 닉네임만 입력.
- **초대코드 입장 (Setlog 방식)**: 한 명이 6자리 코드를 만들고(24시간 유효), 상대가 그 코드를 입력해야만 연결된다. 2명이 차면 더 못 들어온다.
- **포토 캘린더**: 날짜별로 사진을 올리고 ★로 대표사진을 지정하면 월간 달력 칸에 그 사진이 표시된다.
- **일정 분류 색상**: 기념일·생일·식사·여행·데이트·기타. 여러 날 일정(여행)은 막대로 이어진다. 상단 범례를 눌러 분류별로 보이거나 숨길 수 있다.
- **일기 · 하고 싶은 말**: 날짜마다 각자 한 편씩(기분 이모지 + 글). 날짜 상세와 홈 "오늘의 일기"에서 쓰고, 달력에 📝(한 명) / 💌(둘 다) 표시. 상대가 쓰면 알림.
- **일정 체크리스트**: 일정마다 🎒 챙길 것 / 📍 꼭 갈 곳. 여러 날 일정은 항목마다 날짜(1일차·2일차…)를 지정. 날짜 상세에서 체크·바로 추가, 홈 "잊지 말자 체크리스트"에 2주 안 일정의 남은 항목 표시, 달력에 ☑️ 표시. 전날 챙길 것·당일 꼭 갈 곳 리마인더 알림.
- **디자인**: 파스텔 핑크 테마, 본문 나눔스퀘어라운드 · 제목 주아체.
- **자동 기념일**: 사귄 날 기준 100일 단위·주년, 둘의 생일.
- **홈**: D+일수, 다가오는 날(D-day), 오늘의 질문(둘 다 답해야 공개), 최근 소식.
- **앨범 / 버킷리스트**.
- **알림**: 인앱 배너 + 알림함 + 휴대폰 푸시(서버 모드, 웹 푸시). 종류별 켜기/끄기, 방해금지 시간. 기념일·체크리스트 리마인더는 서버가 매일 아침 9시에 보낸다.
- **앱 설치(PWA)**: 홈 화면에 추가하면 앱처럼 열리고, 오프라인에서도 저장된 기록을 볼 수 있다. 아이폰 푸시는 홈 화면에 추가한 앱에서만 된다.
- **회원 탈퇴**: 둘의 기록·사진을 모두 지우고 공간을 닫는다.
- **데모 도구**: 설정 → "상대방 활동 시뮬레이션"으로 상대가 사진·일정을 올린 상황과 알림을 확인한다.
